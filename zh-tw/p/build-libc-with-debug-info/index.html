Note

編譯帶有除錯資訊的 libc

在 Ubuntu 16.04 上編譯帶有完整除錯資訊的 glibc 2.23。

2018-06-22
閱讀時間: 1 分鐘

本文使用環境為 64 bit Ubuntu 16.04

下載原始碼

由 The GNU C Library (glibc) 官方網站下載 glibc source code，以 glibc 2.23 為例

下載 glibc 2.23 並解壓縮

1
2

wget https://ftp.gnu.org/gnu/libc/glibc-2.23.tar.gz
tar zxvf glibc-2.23.tar.gz

設定與編譯

進入 glibc-2.23 資料夾中並新增一個 build 的資料夾供編譯使用

1
2

cd glibc-2.23
mkdir build

進入 build 資料夾並設定編譯參數

  • CFLAGS
    • debug 選項全開並盡量不要做優化
    • 可參考以下範例
  • prefix
    • 編譯完檔案所放位置
    • 範例為放置家目錄下的 glibc 資料夾內
1
2

cd build
CFLAGS='-g3 -ggdb3 -gdwarf-4 -Og -Wno-error' ../configure --prefix=/home/`whoami`/glibc

編譯並安裝

1
2

make -j4
make install -j4

補充：編譯 32-bit glibc

編譯 32 bit 版本的 glibc

  • CC
    • gcc -m32
  • CFLAGS
    • host=i686-linux-gnu
    • build=i686-linux-gnu
1

CC='gcc -m32' CFLAGS='-g3 -ggdb3 -gdwarf-4 -Og -Wno-error --host=i686-linux-gnu --bulid=i686-linux-gnu' ../configure --prefix=/home/`whoami`/glibc
